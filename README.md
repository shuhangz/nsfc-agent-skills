# NSFC申请书撰写辅助智能体技能包

> 本仓库 fork 自 [njzjz/nsfc-agent-skills](https://github.com/njzjz/nsfc-agent-skills)，在原版基础上对 `nsfc-write` 技能进行了增强和优化。

这是一个专为 NSFC 申请书撰写设计的 Agent Skills 集合，帮助科研人员提高申请书质量，涵盖写作指导、图表制作、文献管理和政策速查等核心环节。

## 📦 技能包概览

本项目包含 4 个专业技能，每个技能都可以独立使用：

| 技能名称 | 功能简介 | 适用场景 |
|---------|---------|---------|
| **[nsfc-write](./nsfc-write/SKILL.md)** | NSFC 申请书撰写指南 | 选题、摘要（含四段式撰写模板与句式参考）、立项依据（含递进式结构与存在问题分析模板）、研究内容、研究方案、创新性分析等各部分撰写 |
| **[nsfc-figure](./nsfc-figure/SKILL.md)** | NSFC 申请书图表制作指南 | 概念图、技术路线图、研究内容关系图、甘特图等专业图表制作 |
| **[nsfc-literature](./nsfc-literature/SKILL.md)** | NSFC 申请书文献检索与引用 | 使用 OpenAlex API 检索文献，使用 wenxian 生成标准引用格式 |
| **[nsfc-policy](./nsfc-policy/SKILL.md)** | NSFC 2026 年度申报政策速查 | 限项规定、AI 使用规范、申请代码、项目类型、结构改革等政策信息 |

## 🔧 相比原版的修改内容

以下是对 `nsfc-write` 技能的主要增强，参考了真实获资助申报书的写作范式：

### 摘要
- 提出**底层逻辑四段式**结构（现象与价值 → 现存局限转折 → 本项目方案 → 预期意义）
- 新增通用四段式撰写模板及**各段关键句式参考表**

### 立项依据与研究内容
- 结构从线性罗列改为**三层递进式**（研究意义 → 研究现状 → 解决思路）
- 研究意义新增三层递进引入指导，强调对核心矛盾词组加粗便于评委扫读
- 国内外研究现状改为**按技术逻辑/处理流程**设小标题（而非简单的"国内/国外"划分）
- 新增**"存在问题分析"汇总模板**，将各小节局限汇总为编号列表，与后续研究内容一一对应

### 研究内容与研究方案
- 研究内容新增**总体目标段落**（破题引出）及每项内容的**四要素结构**（问题 → 方法 → 技术方案 → 目标）
- 研究方案新增**数学模型严谨描述四步模板**（定义变量 → 写出核心公式 → 逐符号解释 → 说明约束项的物理动机），附完整示例
- 新增算法子步骤连词规范与总述引领句模板

### 特色与创新
- 采用**四段递进式模板**（问题限制 → 创新突破 → 技术贡献 → 预期成果）
- 按 2026 年官方提纲，可行性分析已并入"研究基础与可行性分析"模块

## 🚀 在 OpenClaw 中使用

本项目遵循 [Agent Skills](https://agentskills.io) 规范，这是一个为 AI 智能体设计的结构化知识库格式。每个技能都是一个包含 `SKILL.md` 文件的目录，文件中包含 YAML frontmatter 和 Markdown 格式的指导内容。

可以直接让OpenClaw安装这些技能，如“安装https://github.com/njzjz/nsfc-agent-skills/ 这个skill”。
